一、实验目的及要求 一：在已划分VLAN的网络中，通过三层设备（路由器）实现不同VLAN之间的主机通信。 二：利用三层交换机的SVI（交换虚拟接口）技术，实现VLAN间的路由。 三：在跨越多个交换机的复杂VLAN环境中，实现VLAN间的通信。 四：在网络中配置RSTP（快速生成树协议），解决二层环路问题，并提高网络的收敛速度。 五：配置MSTP（多生成树协议），实现VLAN流量的负载分担，优化网络带宽利用。 |
| 二、实验原理与内容 一：在路由器的一个物理接口上创建多个子接口，每个子接口封装802.1Q协议并分配一个唯一的VLAN ID，作为对应VLAN内主机的默认网关。数据包在VLAN间传输时，会先发送到路由器进行路由转发，再通过同一个物理接口送回交换机，因此得名“单臂路由”。 二：在三层交换机上为每个VLAN创建一个虚拟接口（SVI），并为其分配IP地址作为该VLAN的网关。三层交换机利用其内部的高效硬件交换结构，在VLAN之间进行高速的数据包路由转发，性能优于单臂路由。 三：结合了VLAN Trunk（通过802.1Q协议在交换机间传输多个VLAN流量）和三层路由技术（可以是单臂路由或SVI）。本实验的重点在于理解如何通过Trunk链路扩展VLAN，并选择合适的路由方案实现跨交换机的VLAN间通信。 四：RSTP是STP的改进版本，通过定义不同的端口角色（根端口、指定端口、替代端口、备份端口）和状态（丢弃、学习、转发），快速阻塞冗余路径中的特定端口，从而消除环路。当活动路径发生故障时，RSTP能快速启用备用路径，实现网络的高可用性。 五：MSTP扩展了RSTP，允许将多个VLAN映射到一个生成树实例（MSTI）中。不同的实例可以有不同的根桥和拓扑结构，从而实现不同VLAN的流量通过不同的路径传输，避免了所有VLAN共享同一棵生成树而导致的链路闲置问题。核心概念包括MST域、实例等。 |
| 三、实验软硬件环境 一：路由器（如锐捷RSR20系列）1台，二层交换机（如锐捷S2600系列）1台，安装了Windows系统的PC 2台，网线若干 二：三层交换机（如锐捷S5750系列或同类支持三层路由的交换机）1台，安装了Windows系统的PC 2台，网线若干 三：三层交换机（如锐捷S5750系列）1台，二层交换机（如锐捷S2600系列）2台，安装了Windows系统的PC 4台，网线若干 四：二层交换机（如锐捷S2600系列）3台，安装了Windows系统的PC 2-3台（用于测试连通性），网线若干（用于构建环形拓扑） 五：二层交换机（如锐捷S2600系列）2-3台，安装了Windows系统的PC 2-4台，网线若干 |

| 四、实验过程（实验步骤、记录、数据、分析） 实验一： 网络拓扑搭建： 两台PC（PC1， PC2）分别连接到交换机的F0/1和F0/2端口。 交换机的F0/24端口与路由器的F0/0端口相连。 交换机配置： # 进入全局配置模式 Ruijie> enable Ruijie# configure terminal  # 创建VLAN 10和VLAN 20 Ruijie(config)# vlan 10 Ruijie(config-vlan)# exit Ruijie(config)# vlan 20 Ruijie(config-vlan)# exit  # 将端口F0/1划分到VLAN 10 Ruijie(config)# interface fastEthernet 0/1 Ruijie(config-if-FastEthernet 0/1)# switchport access vlan 10 Ruijie(config-if-FastEthernet 0/1)# exit  # 将端口F0/2划分到VLAN 20 Ruijie(config)# interface fastEthernet 0/2 Ruijie(config-if-FastEthernet 0/2)# switchport access vlan 20 Ruijie(config-if-FastEthernet 0/2)# exit  # 将连接路由器的端口F0/24配置为Trunk模式，并允许VLAN 10和20通过 Ruijie(config)# interface fastEthernet 0/24 Ruijie(config-if-FastEthernet 0/24)# switchport mode trunk Ruijie(config-if-FastEthernet 0/24)# switchport trunk allowed vlan all # 或使用更精确的命令：switchport trunk allowed vlan 10,20 Ruijie(config-if-FastEthernet 0/24)# end  # 保存配置 Ruijie# write 路由器配置： # 进入全局配置模式 Ruijie> enable Ruijie# configure terminal  # 创建子接口F0/0.10，并关联VLAN 10 Ruijie(config)# interface fastEthernet 0/0.10 Ruijie(config-subif)# encapsulation dot1Q 10  # 封装802.1Q，VLAN ID为10 Ruijie(config-subif)# ip address 192.168.10.1 255.255.255.0 # 配置网关IP Ruijie(config-subif)# exit  # 创建子接口F0/0.20，并关联VLAN 20 Ruijie(config)# interface fastEthernet 0/0.20 Ruijie(config-subif)# encapsulation dot1Q 20  # 封装802.1Q，VLAN ID为20 Ruijie(config-subif)# ip address 192.168.20.1 255.255.255.0 # 配置网关IP Ruijie(config-subif)# exit  # 保存配置 Ruijie(config)# end Ruijie# write 主机配置： PC1: IP地址 192.168.10.10/24， 网关 192.168.10.1 PC2: IP地址 192.168.20.20/24， 网关 192.168.20.1  实验二： 网络拓扑搭建： 两台PC（PC1， PC2）分别连接到三层交换机的F0/1和F0/2端口。无需额外路由器。 三层交换机配置： # 进入全局配置模式 Ruijie> enable Ruijie# configure terminal  # 创建VLAN 10和VLAN 20 Ruijie(config)# vlan 10 Ruijie(config-vlan)# exit Ruijie(config)# vlan 20 Ruijie(config-vlan)# exit  # 将端口F0/1划分到VLAN 10 Ruijie(config)# interface fastEthernet 0/1 Ruijie(config-if-FastEthernet 0/1)# switchport access vlan 10 Ruijie(config-if-FastEthernet 0/1)# exit  # 将端口F0/2划分到VLAN 20 Ruijie(config)# interface fastEthernet 0/2 Ruijie(config-if-FastEthernet 0/2)# switchport access vlan 20 Ruijie(config-if-FastEthernet 0/2)# exit  # 为VLAN 10创建SVI接口并配置IP地址（网关） Ruijie(config)# interface vlan 10 Ruijie(config-if-VLAN 10)# ip address 192.168.10.1 255.255.255.0 Ruijie(config-if-VLAN 10)# no shutdown  # 激活接口 Ruijie(config-if-VLAN 10)# exit  # 为VLAN 20创建SVI接口并配置IP地址（网关） Ruijie(config)# interface vlan 20 Ruijie(config-if-VLAN 20)# ip address 192.168.20.1 255.255.255.0 Ruijie(config-if-VLAN 20)# no shutdown  # 激活接口 Ruijie(config-if-VLAN 20)# exit  # （可选，部分设备需手动开启）开启IP路由功能 Ruijie(config)# ip routing  # 保存配置 Ruijie(config)# end Ruijie# write 主机配置： PC1: IP地址 192.168.10.10/24， 网关 192.168.10.1 PC2: IP地址 192.168.20.20/24， 网关 192.168.20.1  实验三： 网络拓扑规划与搭建： 拓扑描述： SW1（二层交换机）：PC1属于VLAN 10，PC2属于VLAN 20。 SW2（二层交换机）：PC3属于VLAN 10，PC4属于VLAN 20。 L3-SW（三层交换机）：作为核心路由设备。 SW1和SW2分别通过自己的G0/1端口连接到L3-SW的F0/1和F0/2端口。 IP规划： VLAN 10 网关：192.168.10.1/24 VLAN 20 网关：192.168.20.1/24 PC1: 192.168.10.10/24 PC2: 192.168.20.20/24 PC3: 192.168.10.30/24 PC4: 192.168.20.40/24 配置步骤： 步骤一：配置二层交换机SW1 # 创建VLAN SW1(config)# vlan 10,20  # 将端口划入VLAN SW1(config)# interface fastEthernet 0/1 SW1(config-if)# switchport access vlan 10 SW1(config)# interface fastEthernet 0/2 SW1(config-if)# switchport access vlan 20  # 配置连接核心交换机的端口为Trunk SW1(config)# interface gigabitEthernet 0/1 SW1(config-if)# switchport mode trunk SW1(config-if)# switchport trunk allowed vlan all 步骤二：配置二层交换机SW2（配置与SW1类似） SW2(config)# vlan 10,20 SW2(config)# interface f0/1 SW2(config-if)# switchport access vlan 10 SW2(config)# interface f0/2 SW2(config-if)# switchport access vlan 20 SW2(config)# interface g0/1 SW2(config-if)# switchport mode trunk SW2(config-if)# switchport trunk allowed vlan all 步骤三：配置三层交换机L3-SW # 为VLAN 10和20配置SVI接口（网关） L3-SW(config)# interface vlan 10 L3-SW(config-if)# ip address 192.168.10.1 255.255.255.0 L3-SW(config-if)# no shutdown L3-SW(config)# interface vlan 20 L3-SW(config-if)# ip address 192.168.20.1 255.255.255.0 L3-SW(config-if)# no shutdown  # 开启IP路由功能 L3-SW(config)# ip routing 步骤四：配置各PC的IP地址和网关（网关指向对应VLAN的SVI接口地址）。  实验四： 网络拓扑搭建： 将三台交换机（SWA, SWB, SWC）连接成一个三角形环路。例如： SWA的F0/1 连接 SWB的F0/1 SWB的F0/2 连接 SWC的F0/1 SWC的F0/2 连接 SWA的F0/2 将PC连接到任意交换机上。 配置步骤： 步骤一：在所有交换机上启用RSTP # 以SWA为例，SWB和SWC配置相同命令 SWA> enable SWA# configure terminal SWA(config)# spanning-tree mode rstp  # 启用RSTP模式 步骤二：配置根桥和备份根桥 # 目标：指定SWA为根桥，SWB为备份根桥 # 在SWA上配置较小的桥优先级 SWA(config)# spanning-tree priority 4096  # 值越小，优先级越高  # 在SWB上配置一个比SWA大但比默认值（32768）小的优先级 SWB(config)# spanning-tree priority 8192 # SWC保持默认优先级32768 步骤三：（可选）调整端口优先级，影响根端口选择 # 如果希望特定端口成为根端口，可以在对应端口下调整端口优先级 # SWC(config)# interface fastEthernet 0/1 # SWC(config-if)# spanning-tree port-priority 112 查看生成树状态： 使用以下命令查看生成树的详细状态，确认根桥、端口角色（ROOT/DESG/ALTR）和状态（DISC/LEARN/FWD）。 SWA# show spanning-tree SWA# show spanning-tree interface fastEthernet 0/1 记录： 根据show命令输出，可以绘制出最终的生成树拓扑图，并标出被阻塞的端口（角色为ALTR，状态为DISC）。  实验五：   网络拓扑与规划： 拓扑： 两台交换机（SW1, SW2）之间用两条链路互联，形成环路。PC分别接入两台交换机，并属于不同的VLAN。 规划： VLAN： VLAN 10（财务部）， VLAN 20（工程部）。 MST实例： 实例1（MSTI 1）： 映射VLAN 10。指定SW1为根桥。 实例2（MSTI 2）： 映射VLAN 20。指定SW2为根桥。 MST域： 域名LINGNAN，修订号1。 配置步骤： 步骤一：在所有交换机上创建VLAN SW1(config)# vlan 10,20 SW2(config)# vlan 10,20 步骤二：配置MSTP（关键步骤，SW1和SW2配置必须一致） # SW2(config)# spanning-tree mst 1 priority 8192 步骤四：启用MSTP SW1(config)# spanning-tree mode mst SW2(config)# spanning-tree mode mst |
| 五、测试/调试及实验结果分析 实验一：在PC1上打开命令行，执行命令 ping 192.168.20.2。观察并记录ping命令的结果。            测试成功表明单臂路由配置正确。数据包从PC1（VLAN 10）发出，经由交换机的Access端口和Trunk端口到达路由器的子接口F0/0.10。 路由器根据目标IP地址进行路由查询，发现目标网络（192.168.20.0/24）直连在子接口F0/0.20上。 路由器将数据包从子接口F0/0.20发出，通过Trunk链路返回交换机，交换机根据VLAN标签将数据帧转发到VLAN 20的PC2，完成了一次跨VLAN的通信。  实验二：在PC1上打开命令行，执行命令 ping 192.168.0.136。观察并记录ping命令的结果，包括响应时间和稳定性。               说明三层交换机的SVI路由功能正常工作，能够为整个网络内的所有VLAN提供路由服务。 本实验成功模拟了企业网络中常见的接入层-汇聚层结构，验证了集中式VLAN间路由方案的可行性。 实验三： 在不同交换机，不同VLAN上通信            说明三层交换机的SVI路由功能正常工作，能够为整个网络内的所有VLAN提供路由服务。 本实验成功模拟了企业网络中常见的接入层-汇聚层结构，验证了集中式VLAN间路由方案的可行性。 实验四：在PC上执行ping命令，确保网络在RSTP作用下无环路且通信正常。                验证了RSTP的快速收敛特性。当主路径故障时，原先的替代端口能快速转变为转发状态，极大减少了网络中断时间。               实验五：观察两个实例的生成树。在实例1中，SW2上连接SW1的某个端口应为替代端口（阻塞）；在实例2中，情况应相反，SW1上的某个端口被阻塞。这表明VLAN 10和VLAN 20的流量走了不同的主用链路。              实验结果成功验证了MSTP的负载分担能力。通过将VLAN映射到不同的实例并设置不同的根桥，成功地将流量分散到了不同的物理链路上，提高了网络带宽的利用率。 |
| 六、实验结论与体会 实验一：单臂路由​ 结论 本实验成功验证了采用“单臂路由”技术可以实现不同VLAN之间的通信。通过配置路由器的子接口并封装802.1Q协议，使其成为各个VLAN的网关，解决了VLAN间的路由问题。该方案证明了在网络设备有限的情况下，可以利用单台路由器的单个物理接口实现逻辑网络的互联，但其性能受限于单条物理链路的带宽，可能成为网络瓶颈。 实验二：使用SVI实现VLAN间路由​ 结论 本次实验成功地在三层交换机上通过配置SVI（交换虚拟接口）实现了VLAN间路由。验证了SVI作为一种高性能VLAN间路由解决方案的有效性。相较于实验一的“单臂路由”，SVI技术利用三层交换机的硬件交换结构，使数据转发在设备内部高速完成，显著提升了转发效率和网络性能，同时简化了网络拓扑结构，是现代企业网络的核心技术。 实验三：跨交换机实现VLAN间路由​ 结论 本实验成功实现了在跨越多个交换机的复杂网络环境中，通过Trunk链路扩展VLAN，并利用三层交换机的SVI接口进行集中式路由，最终完成了所有VLAN间的通信。该实验综合运用了VLAN、Trunk和SVI技术，证明了基于三层交换机的集中式路由方案能够有效构建可扩展、易管理的中型企业网络，模拟了真实的园区网接入层-汇聚层结构。 实验四：配置RSTP​ 结论 本次实验成功地在存在物理环路的网络中配置了RSTP（快速生成树协议），通过逻辑阻塞特定端口消除了网络环路，并建立了冗余备份路径。通过模拟链路故障，验证了RSTP相比STP具有显著的快速收敛特性，能够在数秒内恢复网络连通性。实验表明，RSTP是实现网络高可用性的关键技术，它巧妙地将物理环路的冗余性转化为逻辑链路的可靠性。 实验五：配置MSTP​ 结论 本实验成功配置了MSTP（多生成树协议），通过创建多个生成树实例并将不同VLAN映射到不同实例，实现了VLAN流量的负载分担。实验验证了MSTP不仅继承了RSTP的快速收敛能力，更通过VLAN感知机制，允许不同VLAN的流量沿不同的最优路径转发，从而极大地提升了网络带宽的利用率。MSTP是构建高性能、高可靠性大型企业网络和数据中心的理想选择。 |
