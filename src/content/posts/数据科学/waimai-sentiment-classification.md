一、实验目的及要求 1. 掌握中文文本数据的预处理流程，包括分词、词表构建、序列化与填充。 2. 理解并实现两种神经网络模型（TextRNN 和 TextTransformer）的前向传播。 3. 掌握模型训练、验证和测试的完整流程，并理解掩码（mask）机制在变长序列中的作用。 4. 对比分析不同模型在文本情感分类任务上的性能差异。 |
| 二、实验原理与内容 一、实验原理 本次实验基于深度学习文本分类原理，对外卖评论进行情感二分类（正面 / 负面）。首先使用 jieba 分词完成中文文本预处理，通过统计词频构建词表，将文本转为数字序列，并利用 padding 统一序列长度。模型方面采用两种神经网络：TextRNN（双向 LSTM） 擅长捕捉文本时序依赖；TextTransformer依靠自注意力机制捕捉长距离语义。模型通过嵌入层将词转为向量，结合掩码 mask 忽略填充无效位，利用全局平均池化提取特征，最后通过全连接层实现情感分类。实验采用交叉熵损失与 Adam 优化器迭代训练，对比两种模型在中文评论情感分类上的性能差异。 二、实验内容 数据处理：加载外卖评论数据集，完成分词、词表构建、文本序列化，划分训练集、验证集、测试集。 模型搭建：搭建 TextRNN 与 TextTransformer 模型，补全嵌入、池化、掩码计算代码。 模型训练：配置损失函数与优化器，完成模型迭代训练，保存最优模型权重。 实验评估：在测试集评估准确率，生成混淆矩阵与分类报告，对比模型参数量与性能。 结果可视化：随机抽取样本，直观对比两个模型的预测效果，分析模型优缺点。 |
| 三、实验软硬件环境 硬件环境：联想拯救者 Legion Y7000P，i7-14650HX 处理器，RTX 4060 8GB 独立显卡，DDR5 内存，1TB SSD。  软件环境：Windows 系统，Miniconda 虚拟环境（Python 3.x），PyTorch 深度学习框架，依赖库包括 jieba、pandas、matplotlib、scikit-learn 等。 |
| 四、实验过程（实验步骤、记录、数据、分析） 一、实验步骤 数据预处理：加载外卖评论数据集，通过 jieba 分词完成文本拆分，统计词频构建词表，将评论文本转为固定长度的数字序列，并按比例划分训练集、验证集与测试集。 模型搭建：实现 TextRNN（双向 LSTM）与 TextTransformer 两种模型，配置词嵌入层、序列特征提取层与分类输出层，添加掩码机制处理填充序列。 模型训练：配置交叉熵损失函数与 Adam 优化器，设置学习率调度器，按轮次完成模型训练，在验证集上监控性能并保存最优权重。 模型测试与分析：在测试集上评估模型准确率，生成分类报告与混淆矩阵，对比两种模型的参数量、训练效率与分类性能。 结果可视化：随机抽取测试样本，对比两种模型的预测结果与置信度，直观分析模型的优缺点。  二、实验记录与数据分析 数据情况：外卖评论数据集共约 1.2 万条，划分为训练集约 8400 条、验证集约 1800 条、测试集约 1800 条，词表大小约为 1.2 万，覆盖高频有效词汇。 训练过程：TextRNN 训练速度较快，模型收敛稳定，验证集准确率稳步提升；TextTransformer 训练参数量更大，初期收敛较慢，但在训练后期准确率略高。 测试结果：两种模型在测试集上的准确率均超过 90%，其中 TextTransformer 对长文本的语义理解能力更强，对复杂情感评论的预测准确率略高于 TextRNN；TextRNN 训练耗时更短，模型体积更小，更适合快速部署场景。 问题分析：低频词与未登录词会影响模型预测效果，可通过调整词表过滤阈值、增加数据增强优化；模型存在轻微过拟合现象，可通过调整 Dropout 比例与正则化强度缓解。 |

__init__(self, vocab_size, embed_dim=128, hidden_dim=256,                   num_classes=2, num_layers=2, dropout=0.5, max_len=128):         super(TextRNN, self).__init__()                  self.hidden_dim = hidden_dim         self.num_layers = num_layers                  self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)                  self.lstm = nn.LSTM(             input_size=embed_dim,             hidden_size=hidden_dim,             num_layers=num_layers,             batch_first=True,             bidirectional=True,             dropout=dropout if num_layers > 1 else 0         )                  self.dropout = nn.Dropout(dropout)         self.fc = nn.Sequential(             nn.Linear(hidden_dim * 2, hidden_dim),             nn.ReLU(),             nn.Dropout(dropout),             nn.Linear(hidden_dim, num_classes)         )          def forward(self, x):         # ===================== 学生填空 1 =====================         embedded = self.embedding(x)                  lstm_out, (hidden, cell) = self.lstm(embedded)                  # ===================== 学生填空 2 =====================         mask = (x != 0).float().unsqueeze(-1)         sum_out = torch.sum(lstm_out * mask, dim=1)         avg_out = sum_out / torch.sum(mask, dim=1).clamp(min=1)                  out = self.dropout(avg_out)         out = self.fc(out)         return out  class PositionalEncoding(nn.Module):     """正弦位置编码"""          def __init__(self, d_model, max_len=5000):         super().__init__()                  pe = torch.zeros(max_len, d_model)         position = torch.arange(0, max_len, dtype=torch.float).unsqueeze(1)         div_term = torch.exp(torch.arange(0, d_model, 2).float() * (-math.log(10000.0) / d_model))                  pe[:, 0::2] = torch.sin(position * div_term)         pe[:, 1::2] = torch.cos(position * div_term)                  pe = pe.unsqueeze(0)         self.register_buffer('pe', pe)          def forward(self, x):         return x + self.pe[:, :x.size(1)]  class TextTransformer(nn.Module):     """基于Transformer编码器的文本分类"""          def __init__(self, vocab_size, embed_dim=128, num_heads=4,                   num_layers=2, dim_feedforward=512, num_classes=2,                  dropout=0.3, max_len=128):         super(TextTransformer, self).__init__()                  self.embed_dim = embed_dim                  self.embedding = nn.Embedding(vocab_size, embed_dim, padding_idx=0)         self.pos_encoder = PositionalEncoding(embed_dim, max_len)                  encoder_layer = nn.TransformerEncoderLayer(             d_model=embed_dim,             nhead=num_heads,             dim_feedforward=dim_feedforward,             dropout=dropout,             batch_first=True         )         self.transformer_encoder = nn.TransformerEncoder(encoder_layer, num_layers=num_layers)                  self.dropout = nn.Dropout(dropout)         self.fc = nn.Sequential(             nn.Linear(embed_dim, dim_feedforward),             nn.ReLU(),             nn.Dropout(dropout),             nn.Linear(dim_feedforward, num_classes)         )          def forward(self, x):         src_key_padding_mask = (x == 0)                  embedded = self.embedding(x) * math.sqrt(self.embed_dim)         embedded = self.pos_encoder(embedded)                  encoded = self.transformer_encoder(embedded, src_key_padding_mask=src_key_padding_mask)                  # ===================== 学生填空 3 =====================         mask = (~src_key_padding_mask).float().unsqueeze(-1)         sum_encoded = torch.sum(encoded * mask, dim=1)         avg_encoded = sum_encoded / torch.sum(mask, dim=1).clamp(min=1)                  out = self.dropout(avg_encoded)         out = self.fc(out)         return out
