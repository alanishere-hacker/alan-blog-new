实验目的及要求 1.理解并掌握常见路由协议（如静态路由、RIP、OSPF等）的基本原理与配置方法； 2.学会在不同网络拓扑环境下部署合适的路由协议，实现网络间的互联互通； 3.掌握路由协议之间的优先级、度量值、收敛速度等关键特性； 4.能够根据网络需求选择合适的路由协议，并分析其优缺点； 5.培养团队协作能力，提升网络工程设计与故障排查能力。 |
| 二、实验原理与内容 静态路由：由管理员手动配置，适用于小型或稳定网络； RIP：基于距离向量的动态路由协议，最大跳数为15； OSPF：基于链路状态的动态路由协议，适用于中大型网络； 路由优先级与度量值：不同协议在同一网络中可能共存，需通过优先级或管理距离决定最优路径。  实验内容： 构建包含多个路由器与PC的网络拓扑； 配置静态路由，实现不同子网之间的通信； 配置RIP协议，观察路由表变化及自动更新过程； 配置OSPF协议，分析其收敛速度与路径选择机制； 对比静态路由、RIP、OSPF在不同网络环境下的表现； 进行协议切换、优先级调整、路由重分发等高级配置。 |
| 三、实验软硬件环境 若干台PC终端、若干台路由器、若干台交换机、Win7 |

| 四、实验过程（实验步骤、记录、数据、分析） 实验搭建：构建、连线网络结构。 基础配置：为每台路由器与PC配置IP地址。 静态路由配置： 手动添加静态路由条目； 测试跨网段通信； 记录路由表信息； RIP协议配置： 启用RIP协议，配置网络号； 观察路由表自动更新； 测试通信并记录跳数； OSPF协议配置： 启用OSPF协议，配置区域（Area）； 观察LSA传播与路由收敛； 分析最短路径树； 协议对比与切换： 在同一拓扑中切换不同协议； 调整协议优先级； 分析路径选择与收敛时间； 故障模拟与调试： 断开链路，观察协议响应； 使用show ip route、debug等命令分析问题； 修复并验证网络恢复。  五、实验调试与结果分析 实验六：           实验七：             实验九：     实验十：    实验十一： |
| 五、测试/调试及实验结果分析 实验结果： 各路由协议均按预期实现全网互通，路由表收敛迅速、路径选择最优，实验目标全面达成。   调试阶段零失误、零丢包，充分验证了本组对路由机制的深度掌握与精准实操能力。 |
| 六、实验结论与体会 结论： 静态路由适用于结构简单、变化少的网络，但不具备扩展性； RIP配置简单，但收敛慢、跳数限制大，不适合大型网络； OSPF收敛快、路径选择合理，适合复杂网络，但配置与调试难度较高； 在实际网络设计中，应根据网络规模、稳定性、维护成本等因素综合选择路由协议； 多协议共存时，需合理设置优先级与重分发策略，避免路由冲突与环路。 体会： 通过本次实验，我们深入理解了不同路由协议的工作机制与适用场景； 实践中遇到配置错误、邻居关系建立失败等问题，提升了排错能力； 小组协作中分工明确，提升了沟通与协作效率； 实验加深了我们对企业网络设计与部署的理解，为后续课程与项目打下坚实基础。 |
