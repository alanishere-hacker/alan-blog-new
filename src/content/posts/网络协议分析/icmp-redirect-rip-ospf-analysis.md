一、实验目的及要求  掌握VLAN Trunk和ARP协议的工作原理，能够配置VLAN Trunk并分析ARP协议的工作流程。 |
| 二、实验原理与内容  实验原理： VLAN Trunk工作原理 VLAN Trunk使用802.1Q协议，在MAC帧中封装VLAN ID等信息，实现跨交换机的相同VLAN通信。 ARP协议工作原理 ARP协议用于根据IP地址解析MAC地址，封装在MAC帧中，实现局域网内的地址解析。 实验内容： 配置ESW1和ESW2的VLAN Trunk，实现PC-1与PC-4、PC-2与PC-4的互通。 在PC-1上ping R2的Loopback地址（3.3.3.3），并在S1-ESW1、ESW1-R1链路上抓包，分析ARP协议流程。 |
| 三、实验软硬件环境 一台PC GNS3网络仿真工具 |
| 四、实验过程（实验步骤、记录、数据、分析）  VLAN TRUNK （802.1Q）协议分析： 1.按照图3所示，配置PC-4的IP地址 进入PC-4的配置界面，输入以下命令： PC-4> show ip    PC-4> clear ip PC-4> ip 10.10.3.3/25 10.10.3.1 PC-4> save 注：PC-4的IP地址应该和PC-1的IP地址在同一个网络，并且网关相同 2.对ESW1进行VLAN trunk设置 进入ESW1的配置界面，输入以下命令： ESW1#configure terminal ESW1(config)#int f1/0 ESW1(config-if)#switch mode trunk ESW1(config-if)#switchport trunk encapsulation dot1q ESW1(config-if)#speed 100 ESW1(config-if)#duplex full ESW1(config-if)#no shutdown ESW1(config-if)#end ESW1#wr    注：在特权模式下使用命令show int trunk或者show vlan-switch brief查看VLAN trunk相关配置信息。 3.对ESW2上增加VLAN 10, 并将f1/1口放入到VLAN 10中 具体配置参考实验一 4.对ESW2进行VLAN trunk设置 配置过程参考ESW1的配置，只需改变接口名称，配置基本一致。 至此，VLAN trunk的配置部分已经完成。 注：此时从PC-1 和PC-2 PING PC-4可以通了。  5.启动抓包，分析VLAN  TRUNK协议  在ESW1和ESW2之间的链路上启动抓包，然后从PC-2和PC-1分别 PING PC-4，分析抓取的数据包。（注意，分析两次PING操作抓包的结果，在实验报告中详细说明） PC-1 PING PC-4： ARP协议分析： 在S1和ESW1的链路上启动抓包，在ESW1和R1的链路上启动抓包； 进入PC-1的配置界面，利用命令show arp查看ARP表是否为空，如果ARP表不为空，则用命令clear arp清除ARP表； 进入ESW1的配置界面，在特权模式下领用命令show arp查看ARP表的情况，注意，如果此时1.1.1.2对应的行，Age(min)对应的值大于零，说明ARP表中该目的地址MAC地址解析生存周期大于零，需要使用clear arp命令清除，使得Age(min)的值变为零。具体操作结果如图4所示。 从PC-1 PING 3.3.3.3 ,从抓包中过滤得到ICMP包，分别分析两端链路ARP工作过程有何 不同。（在实验报告中详细说明） |
