一、实验目的及要求 加深对路由信息协议RIP(Routing Information Protocol)工作原理的理解，掌握RIP路由协议的应用与配置，通过RIP协议相关命令实现动态路由，认识RIP的负载均衡。 |
| 二、实验原理与内容 RIP路由信息协议是真正的距离矢量路由协议。在默认时,它每隔30秒发送一个自己的路由表的完整的拷贝到所有相邻的路由器。在默认时它所允许的最大跳计数为15跳,也就是说到16跳将认为距离是不可达的。由于最大跳计数的限制,在大型网络中是不会使用RIP的。 RIP有两个版本，RIPv2相对与RIPv1来说，增加支持VLSM(可变长子网掩码)和无分类路由选择CIDR，也就是说RIPv2是无类的路由协议，RIPv1是有类的路由协议。 |

| 四、实验过程（实验步骤、记录、数据、分析）  1.拓扑搭建 使用串行DCE线连接R1与R3，需为两者添加HWIC-2T模块（添加时需关闭电源）。 2.路由器配置 R1：配置接口IP（Gig0/0: 192.168.1.2/24, Gig0/1: 10.0.0.1/8, Se0/0/0: 30.0.0.2/8）。 R2：配置接口IP（Gig0/0: 10.0.0.2/8, Gig0/1: 20.0.0.2/8）。 R3：配置接口IP（Gig0/0: 192.168.0.2/24, Gig0/1: 20.0.0.1/8, Se0/0/0: 30.0.0.1/8）。 3.启用RIP协议 在各路由器全局配置模式下执行： router rip network [直连网络地址]  # 如R1添加30.0.0.0、10.0.0.0、192.168.1.0 效果：路由表更新后标记为R（通过RIP学习到的路由），如R 20.0.0.0/8 [120/1]（管理距离120，跳数1）。  4.连通性测试 PC1→PC2： ping 192.168.0.1  # 成功（25%丢包因首次ARP请求超时） tracert 192.168.0.1  # 路径：PC1→R1→R3→PC2 负载均衡验证： R2到30.0.0.1的流量交替经R1和R3（因RIP认为两条路径代价相同）。  关键结论： RIP通过跳数选择最优路径，支持等价路径的负载均衡。 使用show ip route可查看路由表，R标记表示RIP动态路由条目。 |
