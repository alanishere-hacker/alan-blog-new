一、实验目的及要求 部署Loki日志系统，实现本地日志集中化（实时采集、存储查询、可视化展示） |
| 二、实验原理与内容 一、实验原理 本次实验基于集中式日志采集与可视化分析架构，采用 Promtail + Loki + Grafana 组合实现日志的统一管理。 日志采集原理：Promtail 作为客户端，从系统 journald 中实时读取日志，给日志打上标签并推送到 Loki。 日志存储原理：Loki 采用轻量级索引与压缩存储，只索引标签不索引全文，高效存储海量系统日志。 查询与可视化原理：Grafana 通过 LogQL 查询语言从 Loki 获取数据，以图表、面板形式展示日志趋势与统计结果。 容器化部署原理：使用 Docker 与 Docker Compose 实现服务一键部署、网络互通、配置持久化，保证环境一致性。  二、实验内容 环境准备 在 Kali Linux 中安装 Docker 与 Docker Compose，配置国内镜像加速，完成用户权限配置，确保容器可正常运行。 部署日志系统 在指定目录创建 Loki、Promtail、Grafana 配置文件，通过 docker-compose.yml 一键启动三个服务，实现容器互联与自启动。 服务验证 使用 curl 检查 Loki 与 Grafana 端口状态，生成测试日志并查询，确认 Promtail 采集、Loki 存储正常。 Grafana 可视化配置 登录 Grafana，确认 Loki 数据源正常；创建监控仪表盘，分别配置日志级别分布和错误与警告趋势两个面板，实现日志可视化展示。 导出与收尾 导出仪表板 JSON 文件，完成实验后停止容器，整理配置文件与截图，完成实验报告。 |
| 三、实验软硬件环境 Kali Linux虚拟机（已预装Docker + Docker Compose）、VirtualBox、Promtail 2.9.4、Loki 2.9.4、Grafana 10.3.1、curl、jq |
