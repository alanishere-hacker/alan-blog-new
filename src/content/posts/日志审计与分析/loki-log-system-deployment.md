| 二、实验原理与内容 一、实验原理 本次实验基于集中式日志采集架构与 Web 攻击日志分析原理，在实验 2 的 Promtail+Loki+Grafana 平台基础上引入 DVWA 脆弱靶机，形成 “攻击产生日志 — 采集 — 存储 — 可视化 — 分析” 的完整闭环。 日志采集原理：Promtail 同时采集系统日志与 Docker 容器日志，通过配置文件指定日志路径与标签，实现攻击流量的实时抓取。 容器日志原理：DVWA 运行于 Docker 容器，访问与攻击行为均以 JSON 格式记录，可通过挂载容器目录实现采集。 攻击行为日志原理：Web 攻击会在访问日志中留下特征关键字、请求频率、响应状态码等痕迹，可用于识别攻击类型。 可视化分析原理：Grafana 通过 Loki 的 LogQL 查询语句筛选、统计、展示攻击日志，形成可直观识别的面板与图表。  二、实验内容 搭建靶机与日志环境 创建实验目录，复制并修改实验 2 配置文件，新增 DVWA 容器服务，修改 Promtail 配置以支持容器日志采集，通过 Docker Compose 启动 Loki、Grafana、DVWA、Promtail 四个服务。 服务验证与初始化 检查容器运行状态，访问并初始化 DVWA 数据库，设置安全级别为 Low，验证日志采集是否正常。 攻击前日志观察 在 Grafana 中查询 DVWA 日志，查看正常启动与访问状态，记录攻击前日志量、请求类型与面板状态。 执行多种 Web 攻击 依次开展 SQL 注入、暴力破解、目录扫描，并补充命令注入、反射型 XSS、CSRF 等攻击，生成大量攻击日志。 攻击后日志分析 在 Grafana 中对比攻击前后日志差异，通过关键词、请求频率、状态码、时间分布识别攻击行为，构建攻击监控仪表板。 日志对比与总结 对比正常访问与攻击流量的区别，分析不同攻击对应的日志特征，完成实验记录与结果整理。 |
